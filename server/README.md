# 数瞰 V 0.3 · 本地数据服务

在项目根目录使用 `npm run dev` 同时启动网页与 API；构建后 `npm start` 在 **http://127.0.0.1:8787/** 提供网页和接口。也可双击 `启动数瞰.cmd`，旧入口兼容。仅监听 `127.0.0.1`，无数据库、SSR 或微服务。离线演示仍须本地 Node 服务保持运行。

地区、城市及版本由 `public/data/catalog.json` 定义，当前 9 个范围包含 41 个去重城市。白名单从 catalog 城市档案派生，启动时核对档案、发布数据集、区域成员、年份和版本；只在档案出现而未发布的数据不能获得接口准入。统计读取所选版本文件，不以新值覆盖 r1 或 2024 存档。

## 接口

| 方法与路径 | 行为 |
|---|---|
| `GET /api/health?region=prd&dataset=gd-annual-2025-r2` | 返回数据就绪状态、所选范围城市数、基期、范围和版本。省略参数时为默认珠三角九市，因此 `cityCount:9` 不等于全平台总数 41 |
| `GET /api/status` | 返回 `{modelConfigured, model?}`，不包含密钥或服务地址 |
| `GET /api/weather?city=440300` | 接受已发布城市的六位行政代码；结构与 `src/types.ts` 的 `Weather` 一致，失败时 `available:false` |
| `POST /api/analyze` | 根据所选范围、版本、对象和问题返回本地规则或模型补充解读 |

分析输入：

```json
{
  "regionId": "prd",
  "datasetId": "gd-annual-2025-r2",
  "cityId": "440300",
  "question": "深圳的产业结构是什么？",
  "scenario": { "growthDelta": 1.5, "year": 2030 }
}
```

`scenario` 可省略。分析范围可用 `cityId:"all"`；天气接口不接受 `all`。问题最多 1000 字，情景目标为基年之后至 2030 年，增速调整幅度为 -10 至 10 个百分点。整个 JSON 请求限制 12KB。返回 `{mode:'local'|'model',answer,context,sources:[{title,url}],model?}`；来源与上下文记录本次对象、统计期和数据版本。

参数/JSON 错误返回 400，请求过大为 413，未知 API 为 404，服务不可用为 503。天气上游失败返回明确不可用结构，不补造天气。地区与数据集必须匹配，不能用未发布城市绕过准入。

## 天气

固定使用 [Open-Meteo Forecast API](https://open-meteo.com/en/docs)，按已核验城市代表点 WGS84 坐标获取当前温度、湿度、降水、天气代码和风速，并展示从当前小时起的未来 24 小时温度、降水和降水概率。时区 Asia/Shanghai；单位为 ℃、km/h、mm、%。当前天气同样是气象模型输出，不是本项目传感器实测，也不代表全市每个街区。

单次上游请求最长 8 秒，成功缓存 10 分钟、失败缓存 30 秒，同城市并发请求合并。缺字段、超时或网络错误显示不可用，保留来源与失败重试，不把过期缓存伪装成当前天气。城市准入阶段的真实请求及 48 小时原始字段另存 `source-data/v3/weather-admission.json` 和对应原件；这是服务核验记录，不是传感器采样。

## 本地规则和可选模型

默认返回本地计算的规模、排名、产业、人口或解释，不需要模型密钥。问答解析明确指定的城市与年份；多实体问题逐一回应，可从已发布的同年数据说明当前范围外城市，未接入对象明确提示。缺人口不以 0 计算人均值；无情景意图不附加推演。

可选模型配置：复制根目录 `.env.example` 为 `.env.local`，填写 `AI_BASE_URL`、`AI_API_KEY`、`AI_MODEL`，重启服务。只读取本项目配置文件及服务进程环境，不探测其他项目。API 根地址通常以 `/v1` 结尾，服务追加 `/chat/completions`。密钥留在服务端，不发送到浏览器；配置文件不应进入公开提交。

配置完整后尝试兼容 Chat Completions 的服务，超时 20 秒。数字事实和来源由本地数据固定生成，模型仅补充定性说明；不合约束或失败时回落规则解读并提示实际模式。外部模型真实调用及其准确性不因受控测试通过而视为已验证。

## 历史与情景口径

前端本地数据已有部分 2019–2025 官方历史序列：广东 21 城七年完整，其他城市覆盖见 [数据准入记录](../docs/V3-数据准入.md)。缺年不插值、不用增速倒推；各年保留原发布口径，未统一经济普查回溯修订。历史现价金额的同比不能替代官方实际增速。

情景以各市基年 GDP 为基数，把基年实际增速加上用户调整的百分点，**作为假设年均增长率**，复利至目标年；集合值为各市分别计算后相加。金额是固定基年价格的近似情景值，明确假设、非官方预测。历史实际路径使用现价记录，不是未来预测的回测或精度证明。

A/B 双情景与两组参数 CSV 由前端本地计算和导出；本分析 API 的 `scenario` 契约仍是一组可选参数，未新增 A/B 服务端预测接口。没有价格预测、因果模型或重型经济预测系统。

## 构建、数据门禁与验证

`npm run build` 依次执行 `node scripts/pipeline/validate.mjs`、TypeScript 检查和 Vite 构建。校验覆盖城市数与 ID、类型、统计口径、来源、人口、产业舍入差、代表点及几何等；失败时不生成新 manifest。`npm test` 包含服务/API/业务测试与 14 项数据管线正负例；当前共 58 项通过，最终证据见 [V3 交付与验收](../docs/V3-交付与验收.md)。

发布数据版 `zhuliu-v3-20260927-r2` 已冻结，记录在 `source-data/v3/frozen-r2-publication.json`。默认运行 `python scripts/build-v3-data.py` 仅核对散列，不重写冻结版本；未来来源更新应创建新版本。运行产品不依赖 Python。

全国标准栅格、区域边界、统计、字体和 AI 场景均为本地资产；外部天气、在线街道及模型依赖网络。最终网络隔离、控制台及物理拔网状态以总验收记录为准，不能将文件存在或单元测试等同于现场断网通过。
