# 珠流 V1 开发边界

用户已授权开发广东珠三角九市第一版。2026-09-26。

当前目录是应用根，父目录调研报告保留。主 Agent 负责 package、共享类型、App、CSS 和最终集成；地图 Agent 仅写 src/components/CityMap.tsx 及地图专用文件；数据 Agent 仅写 public/data 和数据来源文档；服务 Agent 仅写 server、tests 和环境配置示例。无同文件并行写入，无需 Worktree。

技术决定：React + TypeScript + MapLibre，Node 本地 API。以成熟开源引擎定制作品，避免迁移大型地理浏览器的交互与依赖。模型接入限服务端环境变量，不在前端保存密钥。先采用同一官方表的2024年GDP和产业数据，明确年份，后续可更新数据版本。

首版验收：九市选择联动；本地真实行政区几何，无网络仍可显示区域图；指标图层与二维/三维切换；三市对比；明确假设的发展情景推演与导出；天气API正常或清晰不可用状态；本地数据解读/可配置大模型服务，模式明确；数据来源可见；构建和有意义的业务/API检查及浏览器交互实测。

边界：区域数字底座和数据应用，不声称已有城市级实时传感器、实测交通、精细楼宇全覆盖或经过验证的经济预测。

## 当前交付状态

V1 已实现并完成本地浏览器验收，正式服务为 http://127.0.0.1:8787/，可用根目录“启动珠流.cmd”重新启动。当前没有 Git 仓库和远程部署；依赖由 package-lock.json 锁定。验证证据见 VERIFICATION.md，使用方式见 README.md。

地图使用 MapLibre 6.11.2，须通过 `maplibre-gl-worker.mjs?worker&url` 引用独立 Worker。默认本地地图不访问在线瓦片；在线 OpenFreeMap 楼宇层与本地指标挤出层分开控制。OSM WGS84 原始行政区包含管辖海域，填色使用 Natural Earth 陆地交集；10m 是 1:1000 万比例尺。原始证据只存 source-data，不对网页发布。

助手尚未配置真实模型，当前是有明确标签的本地规则模式。后续可在当前项目 .env.local 填入服务端模型配置；不可从其他项目探测或复用密钥。情景计算不是实际经济预测，后续如增加预测功能需要新的历史序列、方法与验证。

下一轮可以围绕特定真实城市问题加入历史演变、数据联动或可验证的预测任务。用户未指定这一轮的后续专题，不把建议当成新授权或既定规则。
